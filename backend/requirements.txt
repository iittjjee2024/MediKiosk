# MediKiosk backend dependencies.
#
# Deliberately minimal: the clinical NLU, engines and services use only the
# Python standard library (json, re, math, hashlib, hmac, unicodedata,
# dataclasses), so there are no ML/GPU packages here. Authentication uses
# stdlib PBKDF2/HMAC, not a crypto dependency. This keeps the image small and
# the install fast, and it runs on CPU-only commodity hardware.
